# Bramante Research

Static website for **Bramante Research**, the commercial real estate research and advisory division of Bramante Group, LLC.

- Single `index.html` — Tailwind CSS via CDN, Google Fonts (Cormorant Garamond + Inter)
- Hosted on GitHub Pages from the `main` branch (no build step)

## Updating content

- **Drone footage:** replace the contents of `#hero-media` in `index.html` (embed snippets are in the HTML comment there).
- **Report PDFs:** add files to a `reports/` folder and point each card's "Download Brief" `href` at them.
- **Contact:** add your inbox to the `mailto:` link in the Contact section.
